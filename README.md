# Unplug (MVP, rules-only)
Open this folder in Android Studio (Koala or newer), let Gradle sync, run on a real phone.
1. Tap "Grant access" and enable Unplug under Notification Access.
2. Add VIPs / keywords in Rules.
3. Start a session; non-urgent notifications are removed and stored in Digest.
Next steps from the plan: on-device AI classifier (hook into DecisionEngine), feedback buttons, auto-reply.
